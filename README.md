# 📚 B7Web
Repositório dedicado aos meus estudos realizados durante o curso da B7Web. Aqui documento exercícios, desafios e projetos práticos desenvolvidos ao longo da minha evolução como desenvolvedora Front-end.

## Aqui você encontra:
* arquivos de estudos e projetos gerados através do curso B7Web;
* anotações em código para fixação de conteúdo.

## O que vimos até o momento:
### HTML
Durante o módulo de HTML estudei a criação de páginas semânticas, formulários acessíveis, estruturação de conteúdo, SEO básico e boas práticas para construção de documentos HTML.

### CSS 
Já em CSS, aprendi o uso de flexbox, grid, responsividade, variáveis, pseudo-elementos e pseudo-classes, position, animações e transições.

### JavaScript
Em JavaScript, compreendi o que são e como usar variáveis, escopo, arrays, objetos, loops, eventos, DOM, fetch API, async/await, APIs, JSON e localstorage.
